# Real-Time Elephant Detection System for Railway Safety

This project is a prototype designed to help reduce train–elephant collisions. An autonomous trolley moves ahead of a model train and uses sensors to detect an elephant or obstacle near the track.

When an obstacle is detected, the trolley slows down first, followed by the train. A buzzer alerts the train, while sensor readings and system status are displayed through LabVIEW and a web interface.

## Technologies used

- Arduino for sensor readings and motor control
- LabVIEW for monitoring and data processing
- Firebase Realtime Database and a web interface for displaying data
- PIR, ultrasonic, IR, speed, and load-cell sensors

## Project files

This repository contains Arduino sketches, LabVIEW VIs, and the web interface developed for the prototype.
